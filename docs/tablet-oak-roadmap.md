# GridFront Scout Tablet + OAK Roadmap

Working list for the tablet kiosk app and OAK-D standalone camera network.

## Architecture Goal

- Tablet owns setup: machine profile, camera mounting positions, zones, alerts, display preferences, and target display update rate.
- Each OAK-D owns perception: neural detection, stereo depth, tracking, machine-frame coordinate transform, and zone classification.
- OAK-D cameras send compact detection packets to the tablet at the configured rate.
- Tablet renders a merged cab display and provides field-service controls, including Wi-Fi debugging while USB-C is occupied by the OAK/Ethernet chain.
